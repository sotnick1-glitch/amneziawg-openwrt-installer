# AmneziaWG OpenWrt Installer

One-command installer that sets up [AmneziaWG](https://amnezia.org) on an OpenWrt router, using **your own** client configuration file. No servers, keys, or accounts are bundled with this script — it only wires up what you paste in.

[Русская версия ниже](#amneziawg-установщик-для-openwrt)

## What it does

- Installs the AmneziaWG kernel module and tools if they're not already present.
- Creates a network interface (`awg0`) from the client `.conf` you provide.
- Adds NAT/firewall rules so devices on your LAN can use the tunnel.
- Installs a simple on/off toggle page inside LuCI (**Services → AmneziaWG**), so you don't need to dig through Network settings every time.
- Leaves the tunnel **off by default** — nothing routes through it until you flip the switch.

## What it does NOT do

- It does not contain, generate, or transmit any keys, servers, or "activation codes".
- It is not tied to any specific VPN provider or service.
- You need your own AmneziaWG client config (`.conf`) — exported from the Amnezia app, or provided by whoever runs your AmneziaWG server.

## Requirements

- An OpenWrt router (tested on 24.10, may work on other recent versions).
- Your OpenWrt build must have (or be able to install) `kmod-amneziawg`, `amneziawg-tools`, and `luci-proto-amneziawg`. Not every OpenWrt target/feed carries these — see [amnezia-vpn/amneziawg-openwrt](https://github.com/amnezia-vpn/amneziawg-openwrt) if `opkg install` fails.
- Your own AmneziaWG client `.conf` file, already generated by your server.

## Usage

SSH into your router, then run:

```sh
wget -O- https://raw.githubusercontent.com/<your-username>/amneziawg-openwrt-installer/main/install.sh | sh
```

When prompted, paste the full contents of your client `.conf` file, then press Enter followed by Ctrl-D.

Once it finishes, open your router's admin page → **Services → AmneziaWG**, or go directly to `http://<router-ip>/cgi-bin/amnezia`, and press the button to turn the tunnel on or off.

## Safety notes

- The script only ever touches the `awg0` interface it creates and the firewall zone that already has masquerading enabled (usually `wan`) — it does not modify your existing WAN, LAN, or other VPN/proxy setups.
- If you ever get stuck with no internet after toggling, reload the LuCI page — the toggle script has a built-in fallback that restores your normal default route automatically.
- Safe to re-run: running the installer again with a new config simply replaces the `awg0` setup.

# AmneziaWG — установщик для OpenWrt

Установщик в одну команду, который настраивает [AmneziaWG](https://amnezia.org) на роутере с OpenWrt, используя **ваш собственный** клиентский конфиг. Никаких серверов, ключей или аккаунтов внутри скрипта нет — он просто разворачивает то, что вы сами вставите.

## Что делает скрипт

- Ставит модуль ядра и утилиты AmneziaWG, если их ещё нет.
- Создаёт сетевой интерфейс (`awg0`) из вашего клиентского `.conf`.
- Настраивает NAT/firewall, чтобы устройства в вашей локальной сети могли пользоваться туннелем.
- Добавляет простую кнопку включения/выключения прямо в LuCI (**Services → AmneziaWG**), чтобы не лазить каждый раз по настройкам сети.
- По умолчанию туннель **выключен** — ничего не маршрутизируется через него, пока вы сами не нажмёте кнопку.

## Чего скрипт НЕ делает

- Не содержит, не генерирует и никуда не передаёт ключи, серверы или «коды активации».
- Не привязан ни к какому конкретному VPN-сервису.
- Вам нужен свой собственный клиентский `.conf` от AmneziaWG — из приложения Amnezia, или от того, кто держит ваш AmneziaWG-сервер.

## Требования

- Роутер на OpenWrt (проверено на 24.10, вероятно работает и на других свежих версиях).
- В прошивке должны быть (или ставиться) пакеты `kmod-amneziawg`, `amneziawg-tools`, `luci-proto-amneziawg`. Не во всех сборках/фидах OpenWrt они есть — если `opkg install` не находит пакеты, смотрите [amnezia-vpn/amneziawg-openwrt](https://github.com/amnezia-vpn/amneziawg-openwrt).
- Свой клиентский `.conf`-файл AmneziaWG, уже сгенерированный вашим сервером.

## Использование

Зайдите на роутер по SSH и выполните:

```sh
wget -O- https://raw.githubusercontent.com/<your-username>/amneziawg-openwrt-installer/main/install.sh | sh
```

Когда попросит — вставьте полное содержимое вашего клиентского `.conf`-файла, нажмите Enter и затем Ctrl-D.

После завершения откройте админку роутера → **Services → AmneziaWG**, либо сразу `http://<router-ip>/cgi-bin/amnezia`, и нажмите кнопку, чтобы включить или выключить туннель.

## Важно про безопасность

- Скрипт трогает только созданный им интерфейс `awg0` и firewall-зону, где уже включён masquerading (обычно `wan`) — существующий WAN, LAN и другие VPN/прокси-настройки (например Podkop) не затрагиваются.
- Если после переключения пропал интернет — обновите страницу LuCI: в кнопке-переключателе есть встроенная защита, которая автоматически восстанавливает обычный маршрут по умолчанию.
- Скрипт можно запускать повторно — повторный запуск с новым конфигом просто пересоздаст настройку `awg0`.
